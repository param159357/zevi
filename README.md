# Zevi

A marketplace for small digital work — the ₹300 PPT, the ₹400 poster, the ₹500
reel edit that big platforms price out.

See [SPEC.md](SPEC.md) for the product specification and [CLAUDE.md](CLAUDE.md)
for stack, structure, and coding conventions.

## Getting started

```bash
cp .env.example .env.local   # fill in your Supabase project values
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Supabase · Vercel

## Status

Setup only. No product features are implemented yet.
